# **Task Manager | Full-Stack Web Application**
## A Secure, Intuitive and Responsive Platform for Personal Task Management

## Project Overview
Task Manager is a full-stack web application developed to simplify everyday task organisation and improve personal productivity.

## Key Features
- User Authentication: Secure registration and login.
- JWT Authorization: Protects authenticated API endpoints.
- Task Creation: Create tasks with titles, descriptions, and due dates.
- Task Management: View, update, and delete tasks.
- Progress Tracking: Mark tasks as completed or pending.
- Task Filtering: Filter All, Pending, and Completed tasks.

## Application Modules

### 1. User Management
- User registration
- User login and logout
- Password hashing
- Token-based authentication

### 2. Task Management
- Create new tasks
- Add task descriptions and due dates
- Retrieve saved tasks
- Update task completion status
- Delete tasks

### 3. Task Organisation
- View all tasks
- Filter pending tasks
- Filter completed tasks
