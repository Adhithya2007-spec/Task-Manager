Task Manager | Full-Stack Web Application

A Secure, Intuitive and Responsive Platform for Personal Task Management

Project Overview

Task Manager is a full-stack web application developed to simplify everyday task organisation and improve personal productivity. It provides users with a centralised platform to create, organise, monitor, and manage their daily activities through an intuitive and responsive user interface.

The application incorporates secure user authentication, persistent data storage, and task management functionalities, delivering a structured and user-friendly experience.

Key Features

User Authentication: Secure user registration and login functionality.

JWT-Based Authorization: Protects authenticated API endpoints and user-specific operations.

Task Creation: Create tasks with titles, descriptions, and due dates.

Task Management: View, update, and delete existing tasks.

Progress Tracking: Mark tasks as completed or pending.

Task Filtering: Organise tasks based on All, Pending, and Completed categories.

Persistent Data Storage: Store user accounts and task information using MongoDB.

Responsive User Interface: Clean, modern design with an intuitive user experience.
